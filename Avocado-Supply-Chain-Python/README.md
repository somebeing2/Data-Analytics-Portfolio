This project investigates the origins of ingredients for avocado toast in the U.K. market using Python and the Open Food Facts database. 
All analysis, documentation, and findings are contained within the avocado_analysis.ipynb file.
The underlying datasets for this project are located within the data/ sub-folder of this directory. This folder includes:
CSV Files: Raw ingredient data (e.g., avocado.csv, olive_oil.csv, sourdough.csv) containing product attributes and origins.
TXT Files: Category tags used for filtering the datasets (e.g., relevant_avocado_categories.txt).
